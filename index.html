Perfil

Sobre mí

Desarrollador de ecommerce y automatizaciones · Ciudad de México

Construyo tiendas en línea y los sistemas que las mantienen funcionando. No entrego maquetas: entrego código en producción, con inventario conectado, pagos operando y métricas que se pueden leer.

Cómo trabajo

Cada proyecto empieza midiendo, no interpretando. Reviso el sitio actual, el flujo de compra y dónde se pierde el dinero; después diseño la solución completa y la construyo modular, documentada y lista para escalar. Nada de parches temporales.

En qué me especializo

Shopify a fondo: temas custom en Liquid, secciones OS 2.0, Admin API, GraphQL e integraciones de inventario. Aplicaciones modernas: React, TypeScript, Vite y Supabase, desplegadas en Vercel. Automatización: bots de WhatsApp sobre la API de Meta, funciones serverless y procesos que corren solos. SEO técnico: datos estructurados, Core Web Vitals y arquitectura semántica de producto.

Lo que puedes esperar

Archivos completos y listos para producción, sin fragmentos ni instrucciones a medias. Documentación de cada sección. Respuesta el mismo día. Un estándar visual que no se negocia: limpio, claro, rápido y bien diseñado.

Ahora mismo

Operando dos plataformas de comercio electrónico en producción y desplegando un bot de WhatsApp para una convención corporativa de 700 asistentes. Disponible para proyectos nuevos.

SEO Técnico

Diseño de Producto

Portafolio

Proyectos

Trabajo en producción, no conceptos

Tecnocasa Group · Ecommerce Shopify

Plataforma de merchandising para franquiciatarios en todo México. Tema custom sobre Horizon: header con blur progresivo, hero cinematográfico, panel de administración con doble compuerta y catálogo de 65 productos con inventario por QR.

Divina Store MX · Skincare & SEO

Tienda de skincare en React + TypeScript + Supabase sobre Vercel. Pasarela Clip con tokenización del lado del servidor, SEO por ruta, arquitectura semántica de producto y estrategia de tráfico en Pinterest y TikTok.

Convención corporativa · Bot de WhatsApp

Bot para una convención de ventas de ~700 asistentes. Arquitectura serverless en Vercel sobre la API de WhatsApp Cloud de Meta, sin licencias. Registro, agenda, avisos y soporte en tiempo real.

Dashboard de inventario QR

Backend en Vercel con OAuth de Shopify y GraphQL para ajustes de inventario validados por PIN, historial de movimientos y exportación a PDF. Escaneas el código del producto y actualizas existencias desde el celular.

Dashboard financiero

Aplicación de flujo de efectivo con planeación por fecha de cobro, simulación de escenarios, temas claro y oscuro y exportación a PDF. Todo el estado en el cliente, sin dependencias.
